# BCA161: Numerical Methods for Computer Applications

## About the Course

**BCA161: Numerical Methods for Computer Applications** introduces students to computational techniques for solving mathematical problems that are difficult or impossible to solve exactly. The course covers approximating functions, finding roots of equations, and solving systems of linear equations, and it focuses on turning these methods into working programs.

## About This Repository

This repository contains all the **laboratory activities and projects** completed for BCA161. Each activity implements a numerical method covered in class.

## Laboratory Activities

| No. | Activity | Description |
|-----|----------|-------------|
| 1 | **Maclaurin Series** | Approximating functions using a power series expanded around zero. |
| 2 | **Bisection Method** | Finding roots of an equation by repeatedly halving an interval. |
| 3 | **False Position Method** | Finding roots using a straight-line estimate between interval endpoints. |
| 4 | **Newton-Raphson Method I** | Finding roots using tangent-line approximations (part I). |
| 5 | **Newton-Raphson Method II** | Continued application and extension of the Newton-Raphson method (part II). |
| 6 | **Naïve Gauss Elimination Method** | Solving systems of linear equations through forward elimination and back substitution. |
| 7 | **Gauss-Jordan Method** | Solving systems of linear equations by reducing the matrix to its reduced row echelon form. |

## How to Use

1. Clone this repository:
   ```bash
   git clone https://github.com/alteeaa/BCA161-Numerical-Methods-for-Computer-Applications.git
   ```
2. Open the folder of the laboratory activity you want to view.
3. Run the program following the instructions inside that folder.
